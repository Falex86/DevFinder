# DevFinder

A native iOS application built with **SwiftUI** that allows users to search for GitHub profiles and explore developer information.

## Features

- **GitHub Profile Search:** Search for GitHub users by username.
- **Profile Details:** View information about GitHub users.
- **Favorites:** Save favorite profiles for quick access.
- **Native iOS Interface:** Built with SwiftUI for a modern iOS experience.

## Tech Stack

- **Language:** Swift
- **Framework:** SwiftUI
- **API:** GitHub REST API
- **Architecture:** MVVM
- **Tools:** Xcode, Git, GitHub

## Project Structure

- `Models/` — GitHub data models.
- `Services/` — GitHub API communication.
- `ViewModels/` — Search logic and application state.
- `Views/` — User interface and profile screens.
- `FavoritesManager.swift` — Favorites management.

## Getting Started

1. Clone this repository.
2. Open `DevFinder.xcodeproj` in Xcode.
3. Select an iOS simulator or a compatible device.
4. Build and run the application.

## About

DevFinder is a portfolio project demonstrating iOS development with Swift, SwiftUI, API integration, and profile data management.
